How it works

1

Clip

Right-click the page or selection, or use Alt+Shift+C / Alt+Shift+S.

2

Review

A dedicated window opens so you can rewrite with OpenRouter, edit the draft, copy, or dismiss.

3

Save

Write Markdown (.md with YAML) or plain text (.txt) into a folder you choose. Unique filenames only — never overwrites.

Why local-first

Your device holds the key

The OpenRouter API key stays in extension storage. It is sent to OpenRouter only when you rewrite (or when auto-rewrite is on).

Your folder, your files

Saves use the File System Access API. Clipclap reads and writes only the folder you grant — tested with Obsidian vaults, fine for any notes folder.

No Clipclap cloud

There is no Clipclap account, analytics, or backend. Clips and settings stay on your machine.

Features

Shortcuts and context menu

Clip the full page or just the selection without leaving the tab.

Rewrite window

Tone harnesses, searchable model picker, optional auto rewrite and auto save.

Markdown or plain text

Rewrites follow the format you pick so the body matches the file type.

Media as links

Pictures and videos become lightweight references — modest image URLs or watch/poster links, not downloaded binaries.

Requirements

Chromium browser

Compatible with Google Chrome™, and also Edge, Brave, and similar Chromium browsers.

OpenRouter API key

v1 talks only to OpenRouter. Setup guide.

A save folder

Any local folder you control — vault, git repo, or plain notes directory.

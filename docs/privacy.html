Privacy Policy

Last updated: 21 August 2026

Clipclap is a local-first Chromium browser extension. This policy describes what data Clipclap handles and where it goes.

Summary

  • Clipclap does not operate a Clipclap backend, account system, or telemetry.
  • Your OpenRouter API key, settings, and saved files stay on your device.
  • When you rewrite a clip (or enable auto-rewrite), Clipclap sends clip text to OpenRouter using your API key.

Data Clipclap handles

Authentication information

If you paste an OpenRouter API key, Clipclap stores it in browser extension storage on your device. The key is sent to OpenRouter only when Clipclap calls OpenRouter’s API (rewrite or model list).

Website content

When you clip a page or selection, Clipclap reads that page’s content (for example text and media links) in the active tab only for that gesture, using temporary activeTab access. Clipped content is kept in temporary session storage on your device for that flow. Clipclap does not request permanent access to all websites.

Settings and save folder

Settings (format, model, tones, and similar options) are stored in extension storage on your device. The save-folder permission is stored locally via the File System Access API (IndexedDB handle). Saved .md or .txt files are written only to the folder you grant.

What Clipclap does not collect

Clipclap does not collect personally identifiable information, health data, financial data, location, browsing history lists, or activity monitoring (such as keystroke or click logging) as product features. Clipclap does not create a Clipclap account and does not run analytics or advertising trackers.

Third parties

Clipclap does not sell user data. The only third-party service Clipclap contacts is OpenRouter, and only for features you use:

  • Listing models (with your API key).
  • Rewriting clip text (with your API key), when you request a rewrite or enable auto-rewrite.

OpenRouter’s handling of that data is governed by OpenRouter’s own terms and privacy policy. Clipclap does not send your data to a Clipclap-operated server.

Data retention

Data in extension storage and session storage remains on your device until you clear it, uninstall the extension, or change browser storage. Files in your chosen folder remain under your control.

Children’s privacy

Clipclap is not directed at children and is not intended for users under 13.

Changes

If this policy changes, the “Last updated” date above will be revised and the updated page will be published at this URL.

Contact

Questions about this policy: open an issue or contact the maintainer via github.com/phyothihakyaw/clipclap. For security issues, see SECURITY.md.
